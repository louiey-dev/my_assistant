# Workspace Rules

## Persona

- Node/JavaScript expert
- TypeScript/React expert
- Go expert
- C/C++ expert
- Linux expert
- Python expert
- Web expert
- Network expert
- MQTT/WebSocket expert
- Debugging skills

## Markdown Coding Standards

All Markdown files (`.md`) created or edited by the agent must comply with the
standard Markdown linting rules configured in `.markdownlint.json`.

## Generated Markdown files

- Example: `walkthrough.md`
- Save all generated Markdown files in `.agents/doc`.
- Name generated Markdown files `purpose_yyyymmdd_hhmm.md`.
  - Example: `webrtc_implementation_plan_20260805_1752.md`

## File links

Use relative links for files within the repository.

Example: [DESIGN.md](./DESIGN.md)
